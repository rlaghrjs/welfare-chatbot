# 앱 내부 정책 알림 실행

기존 0002 마이그레이션의 정책·버전·알림 테이블을 사용합니다.

```powershell
python -m alembic upgrade head
python -m uvicorn app.main:app --reload
```

별도 터미널에서 프로젝트 루트 기준으로 수집기를 실행합니다.

```powershell
python -m scripts.sync_policies --regions 서울특별시 인천광역시 --interval 3600
```

`--interval`을 생략하면 한 번 실행합니다. 서버와 별도 프로세스로 운영하며 프로세스를 종료하면 자동 수집도 중단됩니다. 중앙 정책과 지정한 시도의 지자체 정책을 페이지별로 수집합니다. 최초 성공 수집은 기준 데이터로만 저장하고 알림을 만들지 않습니다. 이후 내용이 달라졌거나 처음 등장한 정책에 대해 활성 구독을 비교합니다. 조회수 변화는 변경으로 취급하지 않습니다. 한 수집 범위 전체가 성공해야 정책·버전·알림을 함께 커밋합니다. 실패한 범위는 `sync_runs`에 실패 상태를 남기며 다른 범위는 계속 수집합니다. 동일 소스 동시 실행은 PostgreSQL advisory lock으로 막습니다.

프론트 설정의 관심 조건을 등록한 뒤 상단 종 버튼으로 알림을 확인합니다. 30초마다 갱신되며 읽음 표시와 페이지 이동을 지원합니다. 기존 익명 installation 인증을 그대로 사용하므로 다른 사용자의 알림은 조회하거나 읽음 처리할 수 없습니다.

- `GET /api/notifications?offset=0&limit=20`: 알림 목록, 전체 건수, 읽지 않은 건수.
- `PATCH /api/notifications/{id}/read`: 본인 알림 읽음 처리.

조건 필드 간에는 AND, 목록 내에는 OR를 적용합니다. 포함/제외 키워드는 정책명·요약에서 검사합니다. 중앙 정책은 전국으로 취급합니다. 주제는 API의 코드·명칭을 사용하며 지자체 주제 명칭을 중앙 코드로 매핑합니다. 프로필 지역과 만 나이는 구독에서 직접 지정하지 않았을 때 적용합니다. 목록 API에 검증된 나이 자격이 없으므로 나이는 미확인 조건으로 처리합니다. 미확인 조건을 제외하도록 등록하면 해당 알림을 생성하지 않습니다. 알림은 지원 자격 확정이 아닙니다.

현재 변경 감지는 **목록 API에 제공되는 내용**을 대상으로 합니다. 상세 페이지에만 있는 신청 기간·지원 조건 변경은 감지할 수 없습니다. `unavailable`/`restored` 이벤트는 아직 생성하지 않습니다. 목록에서 사라졌다는 이유만으로 정책 종료를 판단하지 않습니다. 브라우저 푸시·이메일은 포함하지 않습니다. 실제 동작에는 `.env`의 PostgreSQL 연결 및 두 복지 API 키가 필요합니다.
